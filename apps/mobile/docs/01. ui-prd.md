# Product Requirements Document (PRD)

## 1. Overview
**Project:** Unique Brew Cafe - Mobile Application
**Objective:** Build a robust, performant, and elegant mobile user interface for the Unique Brew Cafe, providing users with a seamless end-to-end experience for browsing stores, viewing menus, placing orders, and tracking order history.
**Platform:** iOS and Android
**Framework:** React Native (Expo)

---

## 2. Tech Stack & Styling Guidelines
- **Core:** React Native, Expo
- **Styling:** NativeWind v4 (Tailwind CSS for React Native)
- **UI Component Library:** Gluestack UI (for pre-built, accessible, and themeable components)
- **State Management:** React Query (for server state/API data) and Zustand/Context (for local UI/cart state)
- **Routing/Navigation:** Expo Router (file-based routing)

### 2.1 UI/UX Principles
- **Aesthetic:** Modern, clean, and warm (coffee-inspired color palette).
- **Responsive:** Fluid layouts using Flexbox and NativeWind utilities.
- **Accessible:** Proper ARIA labels, contrast ratios, and touch target sizes.
- **Feedback:** Haptic feedback on interactions (buttons, adding to cart) and skeleton loaders during data fetch.

---

## 3. Core Features & User Flows

The mobile application will consume the existing `apps/backend` API services (Auth, Stores, Products, Orders).

### 3.1 Authentication Flow
- **Splash Screen:** App logo and initial loading state.
- **Login Screen:** Email and Password input.
- **Registration Flow:**
  - **Initiate:** Enter email and basic details.
  - **Verify:** Enter OTP sent to email.
- **Forgot Password Flow:** Initiate with email, verify with OTP, and set a new password.

### 3.2 Main Navigation (Bottom Tabs)
The primary navigation paradigm will be a Bottom Tab Navigator consisting of:
1. **Home:** Personalized greeting, featured drinks/pastries, and current active order summary.
2. **Menu:** Categorized list of products.
3. **Cart:** Current items ready for checkout.
4. **Orders:** History of past and current orders.
5. **Profile:** User settings and preferences.

### 3.3 Screens & Interfaces

#### A. Home Screen
- **Header:** User's name, current selected store, and a notification bell.
- **Hero Banner:** Promotional content or new arrivals.
- **Quick Actions:** Reorder last item, Scan loyalty QR.
- **Featured Menu:** Horizontal scroll of recommended products.

#### B. Store Selection Interface
- **List View:** Display all available cafe branches.
- **Search & Filter:** Search by store name or location.
- **Store Card:** Store image, name, status (open/closed), distance, and address.

#### C. Menu & Product Discovery
- **Menu Screen:** Vertical list of categories (e.g., Hot Coffee, Iced Coffee, Pastries).
- **Product Card:** Thumbnail image, title, price, and brief description.
- **Product Details Modal/Screen:**
  - Large product image.
  - Customization options (Size, Milk type, Sugar level, Add-ons).
  - "Add to Cart" sticky footer button with total price.

#### D. Cart & Checkout
- **Cart Screen:** List of added items with swipe-to-delete and quantity adjusters.
- **Order Summary:** Subtotal, taxes, discounts, and total.
- **Checkout Flow:** Select pickup time/store, payment method selection, and order confirmation.

#### E. Order Tracking & History
- **Active Order:** Status timeline (Pending -> Preparing -> Ready for Pickup -> Completed).
- **Order History Screen:** List of past orders with "Reorder" quick-action buttons.
- **Order Details:** Breakdown of a specific past order.

#### F. Profile & Settings
- **Profile Screen:** User details, account settings, saved payment methods, and notification preferences.
- **Logout:** Action to revoke the refresh token and clear session.

---

## 4. Implementation Strategy (Phases)

### Phase 1: Foundation & Architecture
- Initialize Expo Router structure (`app/(auth)`, `app/(tabs)`).
- Configure NativeWind v4 and Gluestack UI theme tokens (Colors, Typography, Spacing).
- Create base reusable UI components (Buttons, Inputs, Cards, Screen Wrappers).

### Phase 2: Navigation & Onboarding
- Build Splash and Onboarding UI.
- Implement Authentication UI (Login, Register with OTP).
- Setup routing guards (prevent access to tabs if unauthenticated).

### Phase 3: Core Shopping Experience
- Build Home Screen and Store Selector UI.
- Implement Menu list and Product Details screens.
- Build the Cart UI with local state management for items.

### Phase 4: Checkout & Order Tracking
- Create Checkout flow UI.
- Implement Orders history list and Active Order status tracker.
- Build Profile and Settings UI.

---

## 5. Gluestack UI & NativeWind Integration Notes
- Use `@gluestack-ui/themed` components for complex accessible components (e.g., Modals, Selects, Accordions).
- Use NativeWind `className` for rapid layout, spacing, and styling of composite views.
- Ensure the `tailwind.config.js` is synchronized with Gluestack's design tokens to maintain a consistent unified design system.
